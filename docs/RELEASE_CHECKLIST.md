# Release Checklist

- [ ] `versionName` atualizado
- [ ] `versionCode` incrementado
- [ ] testes unitários passando
- [ ] lint passando
- [ ] APK release gerado
- [ ] APK assinado
- [ ] atualização sobre versão anterior testada
- [ ] migrations testadas
- [ ] SHA-256 gerado
- [ ] changelog atualizado
- [ ] tag criada
- [ ] GitHub Release criada
- [ ] alpha/beta marcada como prerelease quando aplicável
